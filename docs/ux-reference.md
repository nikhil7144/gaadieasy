# Automobile UX Reference

This platform follows the Propesy/Dealsacre public UX pattern with automobile-specific content.

- City and vehicle intent come first.
- Public pages build trust before asking for an enquiry.
- Filters should be compact, chip-based, removable and URL-shareable.
- Cards should show image, model, city, price, fuel, transmission, key facts and CTA.
- Detail/pricing pages should show hero facts, transparent breakdown, dealer enquiry, finance estimate, specs and FAQs.
- Admin screens should be compact SaaS workspaces, not marketing pages.
- SEO pages are structured by admin selections and render live pricing/model data.
- Theme is bright EV green, supported by slate/white surfaces, blue finance accents and amber tax/fee signals.
